# ADR-017 Local Release-Gate Report - Issue #129

Date: 2026-08-19

Environment:

- Local Windows + Docker Compose
- PostgreSQL 16; disposable validation database plus preserved local synthetic database
- Frontend `http://localhost:3000`; Backend `http://localhost:3001`
- Sandbox/mock mail provider and `.example.local` synthetic addresses only

This report is Local/CI evidence. It does not claim a Staging or Production deployment, a real provider call, or a
real alert-channel integration.

## Repeatable automated gate

From `backend`:

```text
npm run validate:adr017
```

The command builds the current backend, creates a uniquely named temporary local database, applies all 14 migrations,
seeds only synthetic relations, runs the production cancellation/claim SQL and services, rehearses guarded rollback in
a transaction, then terminates its own connections and drops only that temporary database.

The same command is a required `ADR-017 PostgreSQL release gate` job in GitHub Actions; critical E2E waits for this job.
This report records the local execution only, not a yet-to-run PR check.

Observed result:

| Check | Result |
|---|---|
| PostgreSQL deadline -1ms / exact / +1ms | Pass: cancel wins only before; claim wins at and after deadline |
| Three concurrent workers | Pass: 1 winning claim, 1 delivery attempt |
| Cancellation wins | Pass: terminal `canceled`, 0 attempts/provider invocations |
| Worker wins | Pass: terminal `sent`, exactly 1 attempt/provider invocation |
| Restart before provider | Pass: abandoned evidence retained, recovered and sent once |
| Restart after provider boundary | Pass: `delivery_unknown`, no automatic resend |
| Subscription matrix | Pass: `trial/active -> sent`; `expired/suspended -> failed` without provider invocation |
| Resource matrix | Pass: person/location inactive, pending deletion and purged fail closed; recovered active sends |
| Synthetic capacity | Pass: 40 jobs, 2 workers, p95 696ms, p99 714ms, 0 early claims |
| Guarded rollback | Pass: waiting row blocks; terminal rehearsal retains 3 evidence columns |
| >5 second alert path | Pass in Jest: safe aggregate warn event, no tenant/job/PII fields |

The SLO figures are one recorded local run at the declared 40-job/two-worker synthetic capacity. CI must enforce the
thresholds (`p95 <= 2000ms`, `p99 <= 5000ms`) rather than compare exact latency numbers.

## 恢复判断

入口返回 503 与 Backend 停止是两个时点。启动 Backend 后，到期任务可在重新开放入口前执行。发生在途调用、投递结果未知或缺少可信回执时，应保持处理冻结，由值班人与 provider 对账，并在批准恢复范围后再启动。这里使用的失败是明确的 mock 失败。本次保留原库，没有恢复上线前空备份，也没有部署历史测试提交。所有核对完成后仅清理了本轮合成项目。真实宿主、入口和变更窗口由 D17 决定，生产邮件准入仍属 [#180](https://github.com/omajilmanbo/poolduck-mail/issues/180)。

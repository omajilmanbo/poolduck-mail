# A05 单标签页值守续期

2026-11-20（日本时间），固定候选 `a05251897d7fc11d96114606bcaa1807dd96af55`。一个合成操作员在单标签页通过正常 UI 登录。浏览器原生 Cookie 时钟和候选后端的应用时钟使用相同偏移，浏览器单调计时、PostgreSQL 时钟与宿主时钟维持实时时间。[矩阵 A05](business-requirements-matrix.md#A05) · [值守需求记录](https://github.com/omajilmanbo/poolduck-mail/issues/80#issuecomment-5043792596)

| 检查 | 实测结果 |
| --- | --- |
| 值守时长 | 受控 24 小时 17 分 10 秒，实际约 70 秒。 |
| 读取与续期 | 登录 1 次，历史读取最终成功 293 次。其中 197 次直接返回 200，另 96 次在历史请求 401 后续期 201、重新读取 200。登录后的续期失败为 0，真实数据库审计同样记录 1 次登录和 96 次成功续期。 |
| 工作台 | 地点、状态筛选和未提交的扫码草稿持续保留，登录表单未重新出现。 |
| 业务写入 | 扫码、邮件任务、投递尝试各为 0。 |

登录前的一次匿名刷新 401 单独计数。实测覆盖单标签页在线值守和 access Cookie 到期后的恢复。两设备、旧刷新值重放、断网恢复及 refresh Cookie 到达 7 天期限仍待验证。

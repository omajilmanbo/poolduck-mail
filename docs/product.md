# Product Definition

## Product name
未定

## Target customers
日本企业客户 / 据点管理员 / 受付担当者 / 邮件群发或出入管理相关业务用户。

## Problem
客户需要一个 Web SaaS，用于集中管理业务数据、邮件通知、客户账号和订阅权限。

## MVP goal
第一版实现 Web 登录、客户管理、核心业务功能、邮件发送、订阅状态控制和管理员后台。

## In scope for MVP
- 用户登录
- 公司/tenant 管理
- 核心业务数据管理
- 邮件发送
- 订阅状态检查
- 管理员手动开通/停用客户
- 基础日志
- 表数据CSV 导出/导入

## Out of scope for MVP
- 自动更新
- 自动支付
- 自动发票
- SSO
- 手机 App
- 复杂审批流

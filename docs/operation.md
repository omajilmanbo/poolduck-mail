# 运维与故障排查手册（初版）

## 1. 登录失败

排查步骤：
1. 确认用户状态（active/suspended）
2. 检查密码错误次数与锁定策略
3. 检查认证服务日志（401/403）
4. 检查 JWT_SECRET 或 session 配置是否异常

## 2. 邮件发送失败

排查步骤：
1. 查看 `mail_jobs` 中失败状态与错误信息
2. 检查 SMTP/provider 凭据与连接性
3. 检查收件箱地址格式与域名策略
4. 必要时触发重试接口

## 3. 订阅异常

排查步骤：
1. 查看 `subscriptions` 状态与有效期
2. 调用 `/api/license/check` 验证返回
3. 检查时区与过期判断逻辑
4. 确认是否应进入 grace period

## 4. 租户隔离异常（高优先级）

排查步骤：
1. 审查请求中的 tenant 上下文
2. 检查 SQL 查询是否包含 tenant_id 过滤
3. 核查审计日志中越权访问记录
4. 立即阻断可疑访问并升级处理

# 用户操作手册（初版）

## 1. 登录

1. 打开系统登录页
2. 输入 `tenant_id`
3. 输入企业账号邮箱与密码
4. 登录成功后进入扫码工作台
5. MVP 阶段登录状态默认保持 24 小时，便于扫码工作台长时间值守；后续前端可缓存上次使用的 `tenant_id`，减少重复输入
6. 当前最小前端会在浏览器本地保存 access token；退出登录或 token 失效后会清理本地登录态

## 2. 扫码录入

1. 连接扫码枪
2. 选择当前 location
3. 在扫码输入框触发扫码
4. 系统显示识别结果与提交反馈（不支持自定义邮件正文预览）
5. 提交后系统会创建扫码记录和 `queued` 邮件任务，并在扫码记录中显示为“发送中”；本步骤不直接发送真实邮件
6. 可在扫码记录行手动触发 sandbox 发送，发送结果显示为“已发送”或“发送失败”
7. 当订阅状态为 `expired` 或 `suspended` 时，系统应禁用扫码提交、邮件创建、发送与重试入口；`trial` 与 `active` 可继续使用
8. 人员映射列表仅显示脱敏邮箱，完整邮箱不在扫码页面只读接口中展示
9. 当扫码编号没有 active 映射邮箱时，系统记录异常扫码事件，不创建邮件任务

## 3. 查看邮件任务

- 当前工作台在本次会话的扫码记录中显示 `queued` / `sent` / `failed` 对应状态。
- 当前可对 `queued` 任务手动触发 mock/sandbox 发送；独立任务筛选、失败重试、跨会话历史加载和自动轮询刷新尚未提供。

## 4. 常见问题

- 登录失败：联系管理员重置密码
- 登录时提示“无法连接后端 API”：确认后端服务已启动，前端 API 地址正确，并由管理员检查 CORS 白名单
- 扫码无响应：检查设备输入焦点与连接
- 邮件未送达：查看任务状态并联系管理员

# 用户操作手册（初版）

## 1. 登录

1. 打开系统登录页
2. 输入 `tenant_id`
3. 输入企业账号邮箱与密码
4. 登录成功后进入扫码工作台

## 2. 扫码录入

1. 连接扫码枪
2. 在扫码输入框触发扫码
3. 系统显示识别结果与提交反馈（不支持自定义邮件正文预览）
4. 提交后可在任务列表查看状态

## 3. 查看邮件任务

- 可按状态筛选：queued/sent/failed
- 失败任务可申请重试（若权限允许）

## 4. 常见问题

- 登录失败：联系管理员重置密码
- 扫码无响应：检查设备输入焦点与连接
- 邮件未送达：查看任务状态并联系管理员

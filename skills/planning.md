# Planning Skill

When asked to split a feature, output GitHub Issues.

Each Issue must include:
- Title
- Background
- Scope
- Out of scope
- Acceptance criteria
- Test requirements
- Recommended labels
- Risk labels
- Human decision required or not

Rules:
- Each Issue should be 1–8 hours.
- Do not create huge tasks.
- Mark billing/auth/data/security tasks as human approval required.
